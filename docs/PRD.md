# PRD — 抖音广告视频洞察笔记生成器 (ai-ad)

> 版本: v0.2.0  
> 状态: 设计阶段（v0.1 Mock 模式已完成）  
> 更新: 2026-06-07

---

## 1. 产品定位

**一句话定位**：粘贴一个视频链接，自动解析内容、分析广告策略、关联实时资讯，生成一篇有洞察的复盘笔记，并建立你的个人广告灵感库（Swipe File）。

**v0.1 → v0.2 核心变化**：

| 维度 | v0.1 | v0.2 |
|------|------|------|
| 输入方式 | 手动填写 11 个字段 | **粘贴链接，自动解析** |
| 内容理解 | 纯文本描述 | **多模态模型（视频帧 + 语音 + OCR）** |
| 宏观背景 | 模型内化的世界知识 | **实时资讯源增强（X/新闻/RSS）** |
| 分析深度 | 5 Agent 定性分析 | **增加 28 维度评分 + 创意 DNA 提取** |
| 知识积累 | 无 | **向量搜索 + Swipe File + Gap Analysis** |
| UI | 基础表单 | **设计系统重做** |

**参考的 GitHub 项目**：
- `claude-ads` (5.3k stars) — 广告质量评分体系
- `Creative Tagger` — 28 维度创意分类法
- `SeekMoney-ai` — 多平台采集 + 语义聚类
- `Meta Ads Pipeline` — FAISS 向量搜索 + AI 分析
- `video-link-pipeline` — 多平台视频下载 + Whisper 转录
- `newsbox` — 52 源实时资讯管道

## 2. 用户场景

**场景 1：刷抖音看到一条有意思的广告**
> 复制分享链接 → 粘贴到 ai-ad → 系统自动下载视频、提取画面和语音 → 多 Agent 分析 → 2-3 分钟生成笔记 + 自动归档到 Swipe File。

**场景 2：研究某个品类的广告打法**
> 连续粘贴 5-10 条同类广告链接 → 系统自动分析 → 向量搜索找到共性模式 → 输出「这个品类最近在打什么点」的趋势总结。

**场景 3：做内容创作前找灵感**
> 打开 Swipe File → 按行业/钩子类型/情绪筛选 → 找到可复用的创意结构。

## 3. v0.2 功能范围

### 3.1 输入升级

| 功能 | 说明 |
|------|------|
| 粘贴视频链接 | 支持抖音/小红书/TikTok/视频号/B站/YouTube 分享链接 |
| 自动解析 | 解析链接 → 获取视频文件 + 元数据（标题、作者、互动数据） |
| 降级输入 | 如果链接解析失败，回退到 v0.1 手动填写模式 |

### 3.2 内容理解升级

| 层 | 技术 | 输出 |
|----|------|------|
| 语音转录 | Whisper (faster-whisper) | 口播文案全文 + 时间轴 |
| 画面抽帧 | ffmpeg + 场景检测去重 | 关键帧（30-80 张） |
| OCR | Tesseract.js | 画面中的文字覆盖 |
| 多模态理解 | 支持视觉的 LLM | 画面描述、调性、人物、场景 |

### 3.3 分析增强

| 新增功能 | 来源参考 | 说明 |
|----------|---------|------|
| 28 维度评分 | Creative Tagger | 钩子类型、信息角度、制作质量、CTA、情绪…每个维度 1-5 分 |
| 创意 DNA 提取 | viral2viral | 可复用的创意结构、叙事模板、情绪公式 |
| 实时资讯增强 | newsbox | 宏观 Agent 输入中加入当日 X 热点/行业新闻 |
| 质量总评分 | claude-ads | 0-100 综合评分，拆解到各维度 |

### 3.4 知识库（新增）

| 功能 | 说明 |
|------|------|
| 向量化存储 | 每条笔记 embedding 后用 FAISS 索引 |
| 相似广告搜索 | 「找和这条类似的广告」 |
| Swipe File | 按行业/钩子/情绪/评分自动分类的灵感库 |
| Gap Analysis | 发现「这个品类还没人在做的内容角度」 |

### 3.5 输出增强

| 新增 | 说明 |
|------|------|
| 质量评分卡片 | 笔记顶部展示 0-100 分 + 各维度得分 |
| 可操作的启发 | 「你可以偷学什么 / 改什么 / 避免什么」 |
| Swipe File 标签 | 自动打标签，归档到灵感库 |

## 5. v0.2 用户流程

```
粘贴视频链接
    ↓
自动解析（3-10s）
  ├─ 成功 → 展示视频基本信息预览
  └─ 失败 → 回退手动填写表单
    ↓
点击「开始分析」
    ↓
┌─────────────────────────────────────┐
│ 阶段 1: 内容抓取                     │
│ 从链接下载视频 + 元数据 + 评论区      │
├─────────────────────────────────────┤
│ 阶段 2: 多媒体理解                   │
│ Whisper 转录 → ffmpeg 抽帧 → OCR    │
├─────────────────────────────────────┤
│ 阶段 3: 实时资讯获取                 │
│ newsbox → 当日相关热点/趋势          │
├─────────────────────────────────────┤
│ 阶段 4: 多 Agent 分析               │
│ 素材 → 策略 → 用户 → 宏观 → 写作     │
│ 每个 Agent 加 28 维度评分            │
├─────────────────────────────────────┤
│ 阶段 5: 知识库入库                   │
│ embedding → FAISS 索引 → Swipe File │
└─────────────────────────────────────┘
    ↓
查看笔记 + 评分 + Swipe File 链接
```

## 6. 输出笔记结构（v0.2 增强版）

在 v0.1 的 8 个章节基础上增加：

```markdown
## 零、质量评分
| 维度 | 得分 | 说明 |
|------|------|------|
| 钩子设计 | 4/5 | 痛点直击，2秒内建立共鸣 |
| 信任建立 | 3/5 | 成分背书有但不够强 |
| 转化设计 | 4/5 | 限时+社交证明双保险 |
| 差异化 | 3/5 | 和竞品区分度一般 |
| ... | ... | ... |
| **综合** | **72/100** | 中上水平，钩子和转化好，差异化弱 |

## 八、创意 DNA（新增）
- 叙事模板：问题-认同-方案-证明-行动
- 情绪公式：焦虑 → 希望 → 自我奖赏
- 可复用结构：前2秒痛点画面 → 中段成分拆解 → 结尾限时钩子

## 九、Swipe File 标签（新增）
#钩子_痛点直击 #情绪_焦虑转希望 #叙事_问题解决 #行业_美妆
```

## 8. 成功标准（v0.2）

- [ ] 粘贴抖音/TikTok 链接后自动解析视频信息
- [ ] 语音转录准确率 > 90%（中文）
- [ ] 28 维度评分输出可重复（同一条广告两次分析得分偏差 < 5%）
- [ ] 笔记中包含实时资讯关联（标注来源和时间）
- [ ] 历史笔记可通过语义搜索找到相似广告
- [ ] UI 有明确的设计风格，不是默认样式
