## 2. v0.1 → v0.2 架构变化

| 层 | v0.1 | v0.2 | 新增依赖 |
|----|------|------|---------|

| 分析质量 | 纯 LLM | LLM + 28 维度评分 | Creative Tagger 分类法 |
| 知识积累 | 无 | FAISS 向量搜索 | faiss-cpu, sentence-transformers |
| 输出 | 单篇笔记 | 笔记 + Swipe File | — |
| UI | 基础 | Design System | ui-ux-pro-max skill |

## 5. Layer 1: 内容抓取层

### 5.1 支持的平台

| 平台 | 解析方式 | 可获取 |
|------|---------|--------|
| 抖音 | douyin-mcp / yt-dlp | 视频、标题、作者、互动数据、评论区 |
| TikTok | yt-dlp / douyin-mcp | 同上 |
| 小红书 | 链接识别 → 手动补充 | 标题、文案、图片（视频有限） |
| 视频号 | 链接识别 → 手动补充 | 文案（平台限制，抓取困难） |
| B站 | yt-dlp | 视频、标题、简介、弹幕、评论 |
| YouTube | yt-dlp | 视频、标题、描述、字幕、评论 |

### 5.2 降级策略

```
链接输入 → 尝试解析
  ├─ douyin-mcp 成功 → 返回完整元数据
  ├─ yt-dlp 成功 → 返回完整元数据
  ├─ 部分成功（只有标题/文案）→ 用已有信息 + 标记缺失
  └─ 完全失败 → 回退到 v0.1 手动表单
```

## 6. Layer 2: 多媒体理解层

```
视频文件
  ├─→ ffmpeg 场景检测抽帧（每 2-3 秒关键帧，去重后 30-80 张）
  │     → 视觉模型分析每帧：场景/人物/动作/情绪/色调/文字
  │
  ├─→ ffmpeg 提取音频 → faster-whisper 转录 → 口播文案 + 时间轴
  │
  └─→ OCR 提取画面中的文字覆盖（价格、卖点、CTA）
        → 结构化素材报告 (MaterialAnalysis)
```

### 6.1 模型选择

当前阶段（v0.2 早期）：如果 DMXAPI 支持视觉模型（如 GPT-4o / Gemini），直接用多模态模型分析关键帧。

## 7. Layer 3: 实时资讯层

```
newsbox 定时抓取
  ├─ X/Twitter: 行业 KOL + 品牌官号 + 热门话题
  ├─ Reddit: 相关 subreddit
  ├─ RSS: 行业媒体、科技博客
  └─ 新闻 API: 消费市场、平台动态
        ↓
  本地 SQLite 存储（按时间窗口缓存）
        ↓
  宏观背景 Agent 输入增强：
  「以下是你分析广告时可以参考的实时资讯：{news_context}」
```

### 7.1 数据流

- newsbox 作为后台任务定时运行（每 6 小时）
- 分析广告时，查询最近 24-72 小时的资讯
- 按关键词匹配度排序，取 Top 10 作为 Agent 上下文

## 8. Layer 4: 多 Agent 分析层（增强）

### 8.1 28 维度评分体系（参考 Creative Tagger）

| 类别 | 维度 | 评分方式 |
|------|------|---------|
| 钩子 | 钩子类型、开头冲击力、好奇心缺口 | 1-5 分 |
| 信息 | 核心卖点清晰度、声称可信度、差异化 | 1-5 分 |
| 信任 | 背书强度、社交证明、数据支撑 | 1-5 分 |
| 转化 | CTA 明确度、紧迫感、低门槛感 | 1-5 分 |
| 情绪 | 情绪强度、情绪精准度、共鸣度 | 1-5 分 |
| 制作 | 画面质量、音频质量、节奏控制 | 1-5 分 |
| 创新 | 创意新鲜度、品类突破性 | 1-5 分 |

### 8.2 创意 DNA 提取

每个分析完成后提取：
- 叙事模板（问题-方案/前后对比/创始人故事...）
- 情绪公式（焦虑 → 希望 → 自我奖赏）
- 钩子结构（可复用的前 3 秒模式）
- 人群定位（打的是什么人，用什么语言）

## 9. Layer 5: 知识库层

```
分析完成
  ├─→ 笔记文本 → sentence-transformers → embedding (768d)
  │     → FAISS 索引
  │
  ├─→ 结构化标签 → SQLite (行业/钩子/情绪/评分)
  │
  └─→ Swipe File 归档（按标签自动分类）
```

### 9.1 语义搜索

```
用户输入: "找钩子很强的美妆类广告"
  → embedding → FAISS 搜索 → Top K 结果
  → 返回相似笔记 + 相似度分数
```

### 9.2 Gap Analysis

```
同品类已分析 N 条广告
  → 统计常用的钩子类型、情绪、叙事
  → 对比 28 维度全覆盖
  → 输出：「这个品类还没人用的角度：XX」
```

## 10. 错误处理策略

沿用 v0.1 的兜底策略，增加：

| 场景 | 策略 |
|------|------|
| 链接解析失败 | 回退手动表单，提示用户手动填写 |
| 视频下载失败 | 跳过视频分析，只用链接元数据 |
| Whisper 转录失败 | 标记「无语音转录」，只用画面 |
| newsbox 无数据 | 宏观 Agent 只用模型知识（v0.1 模式） |
| FAISS 索引未就绪 | 跳过相似搜索，不影响笔记生成 |
